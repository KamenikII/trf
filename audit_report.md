# Проверка кода: Админ-панель vs Правила проекта

В ходе разработки админ-панели были допущены некоторые отклонения от строгих правил проекта (`rules.md` и использования дизайн-токенов). Ниже представлен список проблемных мест и способы их исправления:

## 1. Цвета (Hardcoded HEX)

По правилам необходимо использовать CSS-переменные из `variables.css` (`--Semantics--...` или `--Primitives--...`), но для оформления цветных бейджей (успех, ошибка, предупреждение) были использованы захардкоженные HEX-коды, так как в проекте не хватало прозрачных оттенков для фонов бейджей (например, светло-зеленого, светло-красного).

**Где исправлять:**

- `AdminUsersPage.css`, `AdminInternshipsPage.css`, `AdminReportsPage.css`, `AdminCompaniesPage.css`, `AdminSettingsPage.css`
- Цвета вроде `#16A34A` (зеленый текст) нужно заменить на `var(--Semantics--success)`.
- Цвета вроде `#DC2626` (красный текст) нужно заменить на `var(--Semantics--error)`.
- Цвета вроде `#D97706` (оранжевый текст) нужно заменить на `var(--Semantics--warning)`.
- Цвета вроде `#2563EB` (синий текст) нужно заменить на `var(--Semantics--info)`.
- Цвета интерфейса (например `#fff`) нужно заменить на `var(--Primitives--neutral--0)` или `var(--Semantics--primary-foreground)`.

**Как исправлять:**
Определить в `variables.css` токены для фонов бейджей (например, `--Semantics--success-muted: #F0FDF4;`) и переписать `.css` файлы компонентов с использованием этих переменных.

## 2. Кратность отступов 4px

Большинство отступов (margin, padding, gap) используют семантические переменные (`var(--Spacing--...`), но в некоторых микро-компонентах правило 4px было нарушено для пиксельной корректности:

**Проблемные места:**

- `gap: 2px;` в `AdminDashboardMain.css`
- `padding: 2px 8px;` для бейджиков в `AdminUsersPage.css` и `AdminReportsPage.css`.
- `top: 2px; left: 2px;` для тумблера (Toggle Switch) в `AdminCompaniesPage.css`.

**Как исправлять:**
Заменить значения `2px` на `4px` или добавить спецификацию микро-размеров в `variables.css` (если `2px` допустимо).

## 3. Скругления (border-radius)

Правило гласит: «Используют переменные из variables.css на основе 4px сетки».

**Проблемные места:**

- Использование `border-radius: 100px;` (в бейджах и треках переключателей).
- Использование `border-radius: 50%;` для аватаров пользователей.
- `border-radius: 6px;` для логотипов компаний в `AdminCompaniesPage.css` (должно быть либо 4px, либо 8px, чтобы соответствовать 4px сетке, либо использовать `var(--Radius--...`).

**Как исправлять:**
Для `100px` использовать `var(--Radius--Primitives--radius-full)`. Для `6px` изменить на `4px` или `8px` (`var(--Radius--...`).
