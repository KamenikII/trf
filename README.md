# стажёр.рф — Доска стажировок (React + TypeScript)

Интерактивная доска стажировок для студентов и выпускников.  
SPA-приложение на React (v19) и TypeScript, реализованное по Figma-макету с адаптивной вёрсткой на 3 breakpoints. В проекте настроен роутинг, глобальный стейт-менеджмент через Context API, а также строгая типизация интерфейсов и компонентов.

## Управление состоянием (Context API)

В приложении используется Context API для обеспечения независимости состояния компонентов и избежания проблемы «Prop Drilling».

| Контекст              | Файл `src/context/`     | Назначение                                                    |
| --------------------- | ----------------------- | ------------------------------------------------------------- |
| **AuthContext**       | `AuthContext.tsx`       | Управление состоянием авторизации (залогинен ли пользователь) |
| **FavoritesContext**  | `FavoritesContext.tsx`  | Управление списком избранных стажировок                       |
| **FilterContext**     | `FilterContext.tsx`     | Хранение состояния всех фильтров для списка стажировок        |
| **InternshipContext** | `InternshipContext.tsx` | Предоставление списка стажировок (с учетом загрузки)          |
| **ModalContext**      | `ModalContext.tsx`      | Глобальное состояние всех модальных окон (открыто/закрыто)    |

## Кастомные хуки

Для вынесения логики в переиспользуемые функции созданы кастомные хуки (находятся в `src/hooks/`):

| Хук              | Описание                                                             |
| ---------------- | -------------------------------------------------------------------- |
| `useBodyLock`    | Блокирует прокрутку `<body>`, полезно при открытых модальных окнах   |
| `useDebounce`    | Позволяет отложить вызов функции (например, для оптимизации поиска)  |
| `useEscapeClose` | Отслеживает нажатие «Escape» для закрытия модальных окон             |
| `useFocusTrap`   | Захватывает фокус внутри модального окна для обеспечения доступности |
| `usePostForm`    | Обрабатывает стейт формы размещения новой стажировки                 |

## Дизайн-система

Все дизайн-токены определены в файле `src/variables.css` через систему CSS Custom Properties, разделенную на примитивы (`Primitives`) и семантические токены (`Semantics`).

### Цвета (Semantics)

| Токен                             | Использование                          |
| --------------------------------- | -------------------------------------- |
| `--Semantics--primary`            | Основной цвет (тёмный графит / черный) |
| `--Semantics--primary-foreground` | Цвет текста на основном фоне           |
| `--Semantics--success`            | Успех (зелёный цвет)                   |
| `--Semantics--error`              | Ошибка (красный)                       |
| `--Semantics--warning`            | Предупреждение (жёлтый / янтарный)     |
| `--Semantics--info`               | Информационный (синий)                 |
| `--Semantics--muted`              | Приглушённый цвет (для фонов)          |
| `--Semantics--border`             | Цвет линий границ                      |

### Радиусы скругления

Используют 4px сетку:

- `--Radius--Semantics--radius-button` — для кнопок
- `--Radius--Semantics--radius-card` — для карточек
- `--Radius--Semantics--radius-badge` / `avatar` — для тегов и аватарок

### Модальные окна

Реализованы как отдельные компоненты внутри папок в `src/components/`, они внедряются через централизованный стейт `ModalContext`. Переключение видимости выполняется через соответствующие функции (`openAuthModal`, `closeModal` и др.). Внутри модалок активно используются хуки управления доступностью (`useBodyLock`, `useEscapeClose`, `useFocusTrap`).

## Адаптивная вёрстка

Используются **breakpoints** с медиа-запросами:

| Название    | Диапазон       | `@media`              |
| ----------- | -------------- | --------------------- |
| **Desktop** | > 1080px       | Базовые стили         |
| **Tablet**  | 769px – 1080px | `(max-width: 1080px)` |
| **Mobile**  | ≤ 768px        | `(max-width: 768px)`  |

### Сводка изменений по адаптиву

- **Header:** Расширенная логика профиля. На Desktop — выпадающий `dropdown` аккаунта, на Mobile — интегрированное профильно-бургерное меню со статистикой и навигацией.
- **Profile:** Адаптация страницы профиля. Карточки статистики на Mobile плотно масштабируются (используется `1fr 1fr` сетка с уменьшенными текстами и отступами), аватар уменьшается под мобильный размер (`56px`).
- **Hero:** Оптимизация размера H1 заголовков (уменьшение до 28px) и колонок кнопок на Mobile.
- **Cards Grid:** 3 колонки на Desktop → 2 на Tablet → 1 на Mobile.
- **Toolbar:** Кнопки отдельных фильтров скрыты на Mobile, и показана одна общая кнопка «Фильтры» для вызова FilterModal.
- **Footer:** Перестройка с горизонтального на вертикальный layout для мобильной версии.
